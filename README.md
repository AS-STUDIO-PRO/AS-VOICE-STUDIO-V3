# 🎙️ AS VOICE STUDIO V3

Professional voice cloning & voice design studio — **600+ languages**, one clean interface.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AS-STUDIO-PRO/AS-VOICE-STUDIO-V3/blob/main/AS_VOICE_STUDIO_V3.ipynb)

## Features

- 🎭 **Voice Clone** — clone any voice from a short reference clip, with automatic transcription
- 🎨 **Voice Design** — build a voice from scratch: gender, age, pitch, accent, dialect
- 🗣️ **Non-verbal tags** — laughter, sigh, and more, inserted directly into your text
- 📝 **Subtitles** — auto-generated sentence-level, word-level, and shorts-style SRT files
- 🧹 **Silence removal** — on both the reference audio and the generated output
- 🎚️ **Fine control** — speed, duration, quality, and guidance settings

## How to run

1. Click **Open in Colab** above
2. Run **Cell 1**
3. Run **Cell 2** — a public link will appear, open it
