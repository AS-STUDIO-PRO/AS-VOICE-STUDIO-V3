# 🎙️ AS VOICE STUDIO V3

Professional voice cloning & voice design studio — **600+ languages**, powered by the [OmniVoice](https://github.com/k2-fsa/OmniVoice) engine, wrapped in a fully custom branded interface.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AS-STUDIO-PRO/AS-VOICE-STUDIO-V3/blob/main/AS_VOICE_STUDIO_V3.ipynb)

## Features

- 🎭 **Voice Clone** — clone any voice from a 3–10 second reference clip, with automatic Whisper transcription of the reference audio
- 🎨 **Voice Design** — build a voice from scratch: gender, age, pitch, style (whisper), English accents, Chinese dialects
- 🗣️ **Non-verbal tags** — `[laughter]`, `[sigh]`, `[question-en]`, and more, inserted directly into your text
- 📝 **Subtitles** — auto-generated sentence-level, word-level, and shorts-style SRT files
- 🧹 **Silence removal** — on both the reference audio and the generated output
- 🎚️ **Fine control** — speed, fixed duration, inference steps, guidance scale (CFG), denoise

## How to run

1. Click **Open in Colab** above.
2. Run **Cell 1** (installs the OmniVoice engine — first run takes a few minutes).
3. Run **Cell 2** (launches AS VOICE STUDIO V3 and prints a public `https://xxxx.gradio.live` link — open it).

A free Colab GPU runtime (T4) is enough. Go to `Runtime → Change runtime type → GPU` if it isn't set already.
